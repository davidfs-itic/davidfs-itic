# Documentació mòduls de programació 

Apunts dels mòduls de programació de l'Institut TIC:

- **Desenvolupament mòbil**: aplicacions Android amb Kotlin, amb Views i amb Jetpack Compose.
- **Videojocs**: desenvolupament 2D i 3D amb Unity.
- **Sistemes encastats**: Arduino i IoT.
- **Eines transversals**: Docker i Git.

Cada tema combina l'explicació dels conceptes amb exemples de codi funcionals.
